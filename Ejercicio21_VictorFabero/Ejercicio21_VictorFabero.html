Requisitos del Entorno de Desarrollo

Esta primera sección agrupa los componentes y herramientas necesarias para empezar a programar.


Herramientas indispensables :


  • Editor de código fuente (por ejemplo, VS Code)
  • Navegador web moderno actualizado
  • Ganas de practicar y resolver problemas

Metodología de Trabajo

Esta segunda sección aborda el procedimiento secuencial para el despliegue de un sitio web.


Pasos para publicar una página web :


  1. Escribir la estructura HTML y validar las etiquetas.
  2. Aplicar estilos CSS3 para la presentación visual.
  3. Subir los archivos a un servidor web a través de un hosting.

Conceptos Teóricos

Esta tercera sección recopila los términos teóricos fundamentales del lenguaje de marcas.


Glosario de términos clave :


HTML5
Lenguaje de marcado utilizado para estructurar y presentar el contenido en la web.
CSS3
Lenguaje de hojas de estilo utilizado para describir la presentación visual de un documento HTML.
