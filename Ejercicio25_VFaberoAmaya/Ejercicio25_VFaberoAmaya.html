Instrucciones del Curso

A continuación se detallan los contenidos evaluables e instrucciones generales:

Requisitos generales (Lista no ordenada - ul):

  • Uso correcto de etiquetas semánticas HTML5.
  • Aplicación de hojas de estilo CSS externas o internas.
  • Validación adecuada de los campos de formulario.

Pasos para la entrega (Lista ordenada - ol):

  1. Descargar la plantilla de evaluación.
  2. Completar los ejercicios de tablas y formularios.
  3. Validar el código en el servicio del W3C.
  4. Subir el archivo al aula virtual.

2. Glosario Técnico

Conceptos clave para la evaluación teórica:

HTML5
Lenguaje de marcado estándar para la estructuración y presentación de contenido en la web.
CSS3
Lenguaje de diseño gráfico para definir y estructurar la presentación de un documento estructurado en HTML.
Etiqueta Semántica
Elemento HTML que aporta significado claro tanto al desarrollador como al navegador sobre su contenido (ej. nav, section, article).
